Chave da API Google Gemini (gratuita)

          

          Necessária pro motor Gemini. Fica salva só neste dispositivo (IndexedDB local) e é enviada apenas para generativelanguage.googleapis.com.
          Gere grátis, sem cartão, em aistudio.google.com/apikey → entrar com conta Google → "Create API key".

Sobre esta fase

          

          Fase 1: biblioteca de manuais, chat com citação de fonte garantida pelo app (não depende do modelo formatar certo).
          Fase 2: memória de estudo (aba Training) registrando toda pergunta feita e sugerindo o que revisar, e comparação de revisões (botão 🔄 em Manuals) com classificação de severidade e confirmação manual obrigatória pra mudanças 🔴 críticas.
          Recuperação por palavra-chave local — sem embeddings/backend nesta versão de protótipo.
          Dados salvos localmente no navegador (IndexedDB) — trocar de aparelho ou limpar dados do navegador apaga tudo.
          Comparação de revisões (Fase 2 avançada).
          Fase 3: motor de IA local opcional (offline, mais fraco) — voz foi removida, uso é só por escrita.
          Fase 4: Simulador com cenários dinâmicos, método socrático, sem entregar a resposta antes do piloto decidir.
